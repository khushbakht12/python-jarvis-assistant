# Jarvis AI Desktop Voice Assistant

A Python-based desktop voice assistant inspired by Iron Man's J.A.R.V.I.S.

This project uses speech recognition and text-to-speech technologies to interact with users through voice commands. It can perform various desktop automation tasks such as opening applications, searching the web, telling the time, playing music, and more.

> This project was developed for learning purposes by following CodeWithHarry's tutorial series and may include personal improvements and additional features.

---


## Technologies Used

- Python
- SpeechRecognition
- pyttsx3
- PyAudio
- webbrowser
- os
- datetime
